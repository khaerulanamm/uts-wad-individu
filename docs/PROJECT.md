# Piagam Proyek — Pemesanan Shuttle Kampus

## Bagian A: Identitas & Deskripsi Proyek

- **Nama Aplikasi:** Pemesanan Shuttle Kampus
- **Domain:** Transportasi Kampus
- **Deskripsi Ringkas:** Aplikasi pencatatan dan pengelolaan sesi pemesanan shuttle kampus secara real-time untuk memudahkan mobilitas mahasiswa dan staf kampus antar gedung dan fasilitas.
- **Pengembang Utama:** M. Maulana Khaerul Anam
- **Program Studi / Institusi:** S1 Sains Data - Universitas Cakrawala

## Bagian B: Target Fitur & Layanan Utama

1. **Manajemen Sesi Pemesanan Shuttle:** Pencatatan nama penumpang, rute keberangkatan, waktu, dan nomor kursi.
2. **Pencarian & Pagination:** Pencarian data interaktif berdasarkan nama penumpang atau rute serta pagination.
3. **Validasi & Konfirmasi:** Validasi form input pemesanan di client & server serta dialog konfirmasi pembatalan/penghapusan.
